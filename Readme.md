# Backend Practice 🚀

A collection of my backend development practice using Node.js, Express.js, and MongoDB.

This repository focuses on understanding backend fundamentals, organizing backend code, building APIs, and working with databases using Mongoose.

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- dotenv
- Git & GitHub

## 📚 Concepts Covered

### 1. Backend Fundamentals

- Setting up a Node.js backend project
- Configuring an Express.js server
- Understanding the backend request-response cycle
- Working with environment variables using dotenv
- Organizing backend code into separate modules

### 2. Controllers & Routes

- Creating controllers to handle application logic
- Defining API routes using Express Router
- Connecting routes with controllers
- Understanding separation of concerns

### 3. Middleware

- Understanding Express middleware
- Creating custom middleware functions
- Using middleware for request processing
- Understanding the `req`, `res`, and `next` parameters
- Handling errors and asynchronous operations

### 4. MongoDB & Mongoose

- Connecting the backend to MongoDB
- Creating Mongoose schemas and models
- Performing CRUD operations
- Working with MongoDB documents
- Understanding relationships between models

### 5. MongoDB Aggregation Pipeline

- Understanding aggregation stages
- Filtering documents using `$match`
- Reshaping documents using `$project`
- Adding calculated fields using `$addFields`
- Joining collections using `$lookup`

### 6. Backend Configuration

- Organizing configuration files
- Managing environment variables
- Configuring database connections
- Structuring backend code for maintainability

## 🎯 Learning Goals

- Strengthen backend development fundamentals
- Write clean and modular backend code
- Understand REST API architecture
- Improve database querying and aggregation skills
- Build a strong foundation for advanced backend development
